# Author-derived aggregates

The public release may include small, reproducible aggregate values derived
from cited public sources (for example the premium and connector screening
scenarios in data/public_sources.csv). These rows are explicitly labelled
"author-generated aggregate" and are the only data rows that claim CC BY 4.0.

This directory does not contain third-party raw tables, source PDFs, exact
directed topology, facility mappings, candidate-link geometry, or map files.
An aggregate value is a model scenario or arithmetic transformation, not an
observation, engineering quotation, or permission to redistribute the
underlying source.
